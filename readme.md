# 프로젝트 1. 자동화 도구 비교 실습 (Make vs Zapier)

## 1. 프로젝트 개요
본 프로젝트는 **동일한 자동화 업무를 Make와 Zapier로 각각 구현**한 뒤,  
두 도구의 사용성·설정 난이도·실행 결과 등을 비교 분석하는 것을 목표로 진행하였다.

자동화 주제는 **창업 관련 뉴스 자동 수집 및 알림 시스템**이며,  
RSS 피드에서 뉴스를 가져와 특정 키워드가 포함된 경우에만  
Google Sheets에 저장하고 Gmail로 자동 발송되도록 구성하였다.

---

## 2. 프로젝트 목표
- Make와 Zapier에서 **동일한 자동화 시나리오 구현**
- 두 도구의 **UI/UX, 난이도, 속도, 안정성** 등을 비교
- 실제 자동화가 정상 작동하는지 **실행 결과 확인**
- 어떤 도구가 초보자에게 더 적합한지 분석

# 프로젝트 2 - Zapier를 활용한 이메일 자동 답장 자동화

## 1. 프로젝트 개요
본 프로젝트는 반복적으로 수행되는 이메일 답장 업무를 자동화하기 위해 진행하였다.  
특정 제목(Subject)을 가진 이메일이 수신되면, Gmail 필터가 해당 메일에 라벨을 부착하고, Zapier가 이를 감지하여 자동으로 답장 메일을 발송하도록 구현하였다.

---

## 2. 자동화할 반복 업무 정의
자동화 대상으로 선정한 반복 업무는 **특정 조건의 이메일에 직접 답장하는 작업**이다.  
일반적으로 같은 유형의 문의나 확인 메일에 대해 반복적으로 답장을 보내야 하는 경우가 많기 때문에, 이를 자동화하면 업무 시간을 줄이고 응답 속도를 높일 수 있다.

**자동화 업무 정의:**  
- 특정 제목의 이메일이 도착하면
- 해당 메일을 자동으로 분류하고
- 발신자에게 자동 응답 메일을 전송한다.

---

## 3. 자동화 도구 선정 및 선정 이유

### 선정 도구
- **Zapier**

### 선정 이유
Zapier는 Gmail과 쉽게 연동할 수 있으며, 코딩 없이도 트리거(Trigger)와 액션(Action)을 연결하여 자동화 워크플로우를 만들 수 있다.  
또한 특정 라벨이 붙은 이메일을 감지해 후속 작업을 실행할 수 있어, 이번 프로젝트의 목표인 **이메일 자동 답장 기능 구현**에 적합하다고 판단하였다.

---

## 4. 워크플로우 설계

### 4-1. 워크플로우 설명
본 자동화는 다음 순서로 동작한다.

1. 사용자가 특정 제목의 이메일을 보낸다.
2. Gmail 필터가 해당 메일을 감지한다.
3. 조건에 맞는 메일에 `auto-reply` 라벨이 자동으로 부착된다.
4. Zapier가 `New Labeled Email` 트리거를 통해 라벨이 붙은 메일을 감지한다.
5. Zapier의 `Send Email` 액션이 실행된다.
6. 원래 메일을 보낸 사람에게 자동 답장 메일이 전송된다.

### 4-2. 워크플로우 다이어그램

mermaid
flowchart TD
    A[특정 제목의 이메일 수신] --> B[Gmail 필터 적용]
    B --> C[auto-reply 라벨 부착]
    C --> D[Zapier: New Labeled Email 감지]
    D --> E[Gmail: Send Email 실행]
    E --> F[발신자에게 자동 답장 전송]

---

## 5. 구현 과정

### 5-1. Gmail 설정
Gmail에서 auto-reply 라벨을 생성하였다.
특정 제목(Subject)을 기준으로 필터를 설정하였다.
필터 조건에 맞는 메일에 auto-reply 라벨이 자동으로 붙도록 설정하였다.

### 5-2. Zapier 설정
Trigger: Gmail - New Labeled Email
Action: Gmail - Send Email

### 5-3. 주요 설정 내용
Trigger 라벨: auto-reply
To: 원본 메일의 발신자 이메일 (From Email)

Subject: Re: 원본 제목
Body: 미리 작성한 자동 응답 메시지
예시 자동 응답 본문:

안녕하세요.
메일 잘 받았습니다.

현재 자동 응답 메일입니다.
확인 후 가능한 한 빠르게 답변드리겠습니다.

감사합니다.

## 8. 실행 결과
테스트 결과, 특정 제목의 이메일이 수신되었을 때 Gmail 필터가 정상적으로 동작하여 auto-reply 라벨이 부착되었다.
이후 Zapier가 해당 메일을 감지하여 자동으로 답장 메일을 발송하였으며, 실제로 발신자 메일함에서 자동 응답 메일이 도착한 것을 확인하였다.
즉, 본 프로젝트의 자동 실행 구조는 정상적으로 구현되었다.

## 9. 기대 효과
반복적인 이메일 답장 업무를 줄일 수 있다.
메일 응답 속도를 높일 수 있다.
단순 반복 업무를 자동화하여 업무 효율을 향상시킬 수 있다.

## 10. 결론
이번 프로젝트에서는 Zapier와 Gmail을 연동하여 특정 조건의 이메일에 대해 자동으로 답장을 보내는 시스템을 구현하였다.
Gmail 필터와 라벨을 활용해 메일을 분류하고, Zapier가 이를 감지하여 후속 액션을 수행하도록 구성함으로써 반복 업무 자동화의 기본 구조를 성공적으로 구현하였다.
